# 🤖 LEGO SPIKE + Cámara M-Vision

## Robot programado con Pybricks (LEGO Inventor) y cámara OpenMV (MATRIX M-Vision)

Proyecto de robótica utilizando un robot **LEGO SPIKE** programado con **Pybricks** e integrado con la cámara **M-Vision de MATRIX**, basada en **OpenMV**.

### 🧩 Tecnologías utilizadas

* 🤖 LEGO SPIKE
* 🐍 Pybricks
* 📷 MATRIX M-Vision
* 🔍 OpenMV
* 💻 Python
* 👁️ Visión artificial

### 🚀 Descripción

El robot utiliza **Pybricks** para controlar los motores y sensores del LEGO SPIKE, mientras que la cámara **M-Vision de MATRIX**, basada en **OpenMV**, permite implementar funciones de visión artificial para detectar y analizar elementos del entorno.
